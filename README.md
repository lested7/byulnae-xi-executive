# 별내자이 더 스타 이그제큐티브

별내자이 더 스타 이그제큐티브를 소개하는 반응형 정적 홈페이지입니다.

## 구성

- `index.html` — 프로젝트 소개와 페이지 콘텐츠
- `styles.css` — 반응형 디자인과 시각 스타일
- `script.js` — 모바일 메뉴와 로그인 없는 관심고객 등록 처리
- `supabase-config.js` — Supabase 프로젝트 URL과 브라우저용 공개 publishable key 설정
- `supabase-schema.sql` — 비로그인 접수와 고객정보 조회 차단을 위한 테이블/RLS 설정

별도 빌드 과정 없이 정적 호스팅에 배포할 수 있습니다. 현재 공급 현황과 계약 조건은 자이 공식 안내를 확인하도록 연결했습니다.

## 관심고객 등록

무료 Supabase 프로젝트 `byulnae-interest`에 연결되어 있습니다. 접수 테이블은 `supabase-schema.sql`로 설정합니다. 브라우저에는 공개용 publishable key만 사용하며, secret/service_role 키는 절대 넣지 않습니다.

폼은 이름, 휴대폰 번호, 동의 여부와 시각을 저장합니다. 비로그인 방문자는 등록만 할 수 있고, `anon` 및 `authenticated` 역할에는 고객정보 조회 권한을 주지 않습니다. 고객정보는 프로젝트 소유자가 Supabase 대시보드에서 확인합니다. 실제 고객 접수를 운영하기 전에 개인정보 수집 목적, 항목, 보유 기간, 운영 주체와 연락처를 화면에 구체적으로 안내하세요.
